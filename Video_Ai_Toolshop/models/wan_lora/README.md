# Wan 2.2 I2V Dual-Expert LoRA Training Guide

## Overview

This guide covers training a dual-expert LoRA on Wan 2.2 I2V using [musubi-tuner](https://github.com/kohya-ss/musubi-tuner). Wan 2.2 uses a Mixture-of-Experts (MoE) architecture with two experts gated by timestep:

- **High-noise expert** (t > 0.9): Controls composition, layout, and motion
- **Low-noise expert** (t < 0.9): Controls texture, identity, and fine details

We train one LoRA per expert and load both at inference. This matches the native MoE architecture for optimal quality.

**Track B (Optional):** This is the video LoRA path. Track A (Flux image LoRA → Wan I2V generation) is the primary pipeline. Track B is a quality enhancement for better temporal identity consistency — add it if identity drift is observed in generated clips.

## Dataset Preparation

### Video Clip Collection

Collect **10-20 short video clips** of the subject:
- Duration: 2-5 seconds each
- Face clearly visible throughout
- Varied actions: talking, walking, turning head, different expressions
- Resolution: 480x720 or higher
- Consistent lighting within each clip
- Format: MP4 (H.264)

### Captioning

Each video clip needs a text file with the same basename (`clip_001.mp4` → `clip_001.txt`):

```
ohwx person, [physical description], [action/pose], [setting], [lighting]
```

Example:
```
ohwx person, man with short dark hair and brown eyes, smiling and turning head, in modern office, soft natural lighting
```

### Directory Structure

```
dataset/
├── video_clips/
│   ├── clip_001.mp4
│   ├── clip_001.txt
│   ├── clip_002.mp4
│   ├── clip_002.txt
│   └── ...
└── wan_dataset_config.toml    # Auto-generated by train_wan_lora.py
```

### Upload to RunPod

```bash
scp -r dataset/video_clips/ root@<runpod-ip>:/workspace/dataset/
```

## Two-Stage Training (Primary)

Matches Wan 2.2's native MoE architecture. Trains two LoRAs sequentially.

### Quick Start

```bash
python /workspace/scripts/train_wan_lora.py \
    --dataset /workspace/dataset/video_clips \
    --output /workspace/models/wan_lora \
    --model /workspace/models/Wan2.2-I2V-A14B \
    --rank 32 --lr 2e-5 --steps 2000 \
    --optimizer came
```

### What Happens

1. **High-noise expert** (t=0.9-1.0): 2000 steps, learns composition/motion
2. **Low-noise expert** (t=0.0-0.9): 2000 steps, learns texture/identity
3. Both `.safetensors` saved to `models/wan_lora/high_noise/` and `models/wan_lora/low_noise/`

### Hyperparameter Reference

| Parameter | Default | Range | Notes |
|-----------|---------|-------|-------|
| `--rank` | 32 | 32-64 | 32 for characters, 64 for complex motion |
| `--alpha` | 16 | rank//2 to rank | alpha=rank//2 is conservative |
| `--lr` | 2e-5 | 1e-5 to 8e-5 | Lower than community defaults (1e-4+). Critical for Wan |
| `--steps` | 2000 | 2000-4000 | 2000 baseline, 3000-4000 for refinement |
| `--optimizer` | came | came, adamw, adamw8bit | CAME + LoRAPlus (ratio 4) outperforms AdamW |
| `--frames` | 12 | 8-16 | 12 is compromise between motion and VRAM |
| `--resolution` | 480x720 | 480x720, 1280x720 | 480 for training, 720 for final quality |

## Three-Stage Training (Optional Advanced)

Adds a mid-noise stage for finer motion refinement. Departs from native MoE boundary but can improve motion smoothness.

```bash
python /workspace/scripts/train_wan_lora.py \
    --dataset /workspace/dataset/video_clips \
    --output /workspace/models/wan_lora \
    --model /workspace/models/Wan2.2-I2V-A14B \
    --rank 32 --lr 2e-5 --steps 2000 \
    --optimizer came \
    --stages 3
```

### Three-Stage Timestep Ranges

| Stage | Timestep Range | Purpose |
|-------|---------------|---------|
| High | 0.9 - 1.0 | Composition, layout, scene structure |
| Mid | 0.5 - 0.9 | Motion refinement, movement coherence |
| Low | 0.0 - 0.5 | Texture, identity, fine facial details |

Three `.safetensors` files are saved: `high_noise/`, `mid_noise/`, `low_noise/`.

## Budget GPU: Wan 2.2 TI2V-5B on RTX 4090

For 24GB VRAM, use the 5B model with fp8 + block swap:

```bash
python /workspace/scripts/train_wan_lora.py \
    --dataset /workspace/dataset/video_clips \
    --output /workspace/models/wan_lora \
    --model /workspace/models/Wan2.2-TI2V-5B \
    --rank 32 --lr 2e-5 --steps 2000 \
    --optimizer came \
    --fp8 --blocks-swap 20
```

### A14B vs 5B Comparison

| Feature | I2V-A14B | TI2V-5B |
|---------|----------|---------|
| VRAM (training) | 80GB | 24GB (fp8 + block swap) |
| VRAM (inference) | 80GB | 24GB (fp8) |
| Quality | Best | Good (slightly lower fidelity) |
| Cost/hr | $1.39 (A100) | $0.69 (4090) |
| Training time | ~30-45 min/expert | ~15-25 min/expert |

## Validation

After training, validate identity preservation:

```bash
python /workspace/scripts/validate_wan_lora.py \
    --high-noise-lora /workspace/models/wan_lora/high_noise/pytorch_lora_weights.safetensors \
    --low-noise-lora /workspace/models/wan_lora/low_noise/pytorch_lora_weights.safetensors \
    --reference /workspace/dataset/video_clips \
    --output /workspace/output/test_clips \
    --low-noise-scale 1.3
```

### Identity Score Interpretation

| Score | Status | Action |
|-------|--------|--------|
| ≥ 0.7 | Good | Proceed to video generation |
| 0.6 - 0.7 | Acceptable | Consider boosting low-noise scale to 1.5 |
| < 0.6 | Failed | Retrain with adjusted hyperparameters |

### Three-Stage Validation

```bash
python /workspace/scripts/validate_wan_lora.py \
    --high-noise-lora /workspace/models/wan_lora/high_noise/pytorch_lora_weights.safetensors \
    --mid-noise-lora /workspace/models/wan_lora/mid_noise/pytorch_lora_weights.safetensors \
    --low-noise-lora /workspace/models/wan_lora/low_noise/pytorch_lora_weights.safetensors \
    --reference /workspace/dataset/video_clips \
```

## Inference Guidance

### Loading Both LoRAs

At inference, load both expert LoRAs simultaneously. The high-noise LoRA is active during early denoising steps, the low-noise LoRA during later steps — this is handled automatically by the MoE gating.

### LoRA Scale Tuning

| Scale | Effect |
|-------|--------|
| 0.8 | Subtle influence, more base model character |
| 1.0 | Balanced (default) |
| 1.3 | Stronger identity (recommended for low-noise expert) |
| 1.5 | Maximum identity, may cause artifacts |

**Recommendation:** Start with high-noise=1.0, low-noise=1.3. Boost low-noise to 1.5 if identity drift persists.

### ComfyUI Integration

In ComfyUI, use the WanVideoWrapper node and load both LoRA files. Set `strength_model` for each:
- High-noise LoRA: `strength_model = 1.0`
- Low-noise LoRA: `strength_model = 1.3`

## Iteration Strategy

If identity similarity is below threshold, iterate with adjusted parameters:

| Iteration | Rank | LR | Steps | Optimizer | Expected Improvement |
|-----------|------|----|-------|-----------|---------------------|
| 1 (baseline) | 32 | 2e-5 | 2000 | CAME | Establish baseline |
| 2 (more capacity) | 64 | 1e-5 | 3000 | CAME | More identity detail |
| 3 (max fidelity) | 64 | 5e-6 | 4000 | CAME | Final refinement |

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| CUDA OOM | Model too large for VRAM | Use `--fp8 --blocks-swap 20` (5B) or A100 80GB (A14B) |
| Identity drift in clips | Low-noise expert undertrained | Increase steps to 3000-4000, boost `--low-noise-scale 1.5` |
| Motion artifacts | High-noise expert overfit | Reduce `--high-noise-scale 0.8`, increase dataset diversity |
| No face detected in validation | Generation prompt lacks trigger | Ensure `ohwx person` is in generation prompt |
| Training loss not decreasing | LR too low or optimizer mismatch | Try `--lr 5e-5` or switch to `--optimizer adamw` |
| Clips too short/long | Frame count mismatch | Adjust `--frames 8` (lower VRAM) or `--frames 16` (more motion) |
| Block swap too slow | CPU offload bottleneck | Reduce `--blocks-swap 10` if VRAM allows, or use A100 |
