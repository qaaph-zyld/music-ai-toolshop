## 1. Mission (unchanged, by 2027-07)

**A complete, self-hosted studio toolkit that takes a track from idea to finished master — and
that learns from a corpus rather than guessing.** CPU-first, offline-capable, one repo, adapters
over rewrites, data outside git, every claim verified before it enters a record.

The mission is not "more AI features". It is **compounding daily use**: the suite should be the
default way tracks get made here, and each lane should make the next one cheaper.

## 4. The goal set

Each goal now carries a **status** and a **definition of done** you can check mechanically.

Nothing else starts until the tree, the records, and the backup agree with reality.

**Done when:** `toolshop closeout` exits 0 · `toolshop doctor` returns OK · every lane in the repo has

decision · backup age under 7 days on a destination with headroom · **the backup manifest provably

**New this cycle:** R2 gives M3 a concrete first move — the parity-verified **HT-Demucs FT ONNX

**Reality check:** melody-carrier already opened the composition/MIDI lane ungated, and `ai_modules`

## 7. Governance — binding, with the gaps v1.0 missed

Rules 1-6 from v1.0 §7 stand (CPU-budget measurement, adapter + ledger, data boundary, close-out
discipline, one integration per session, research-gated expansion). Three additions, each written
against a failure that actually occurred:

7. **Commit messages must describe their contents.** `31224e5` shipped a 6,390-line lane under a
   submodule-chore message. No automated gate can catch this — a lane-sized diff (>500 lines or a
   new top-level package) requires its CHANGELOG number in the commit subject.
8. **New top-level packages are lanes, not files.** A new directory under the repo root or a new
   `toolshop/` subpackage needs a plan, a STATUS row, a dependency extra, and its tests inside
   `tests/` where `pytest.ini` will collect them.
9. **Fallback paths must be declarable.** Any module with a primary ML backend and a heuristic
   fallback needs a `--require-advanced` guard, following the pattern that caught the reverse-engineering
   silent-fallback incident. Recording which path ran is necessary but not sufficient.

index of what exists. The audio earns a real second copy when a second **physical disk** exists,
which is goal G5, not a same-box duplicate.
