## 4. Gotchas that cost time this session

- **`git add -A` is unsafe in this repo.** A concurrent session writes here continuously and has
  modified a tracked file (`ORCHESTRATION/prompts/prompts_index.md`). **Always stage explicit paths.**
  `closeout` will report a dirty tree that is not yours — declare it per the "clean tree or declared"
  rule rather than committing it.
- **`toolshop/production_analyzer/batch_analyzer.py` writes to CWD.**
  `BatchAnalyzer.__init__(db_path="production_analysis.db")` is a *relative* default, so running its
  test drops a DB in the repo root. **This is debt 13b's exact shape in newly-adopted code** — it
  should be gitignored and/or given an absolute default under `data/`. Not fixed (no-code instruction).
- **The suite takes 6–13 minutes.** Never run it concurrently with a timing measurement; it will
  corrupt the numbers.
- **Kill the watcher with the process it watches.** Three `until … sleep` loops were leaked here
  before the user spotted them. Prefer bounded `for i in $(seq 1 N)` polling.
- **`mastering_tool` engine is `master_pipeline_v3.sh` via WSL**, not the tray EXE:
  `bash master_pipeline_v3.sh <src.wav> <name> <project_dir> <profile>`. The EXE is a GUI wrapper.
- **In `Distro_Kidea/`, `*_MASTER_32f.wav` files are already mastered.** The `MixAll` files are the
  actual premasters.
